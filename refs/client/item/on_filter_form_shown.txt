====================
on_filter_form_shown
====================

on_filter_form_shown(item)

The item parameter is the item that triggered the event.

**domain**: client 

**language**: javascript

Description
===========

**on_filter_form_shown** 事件在表单窗体已经显示后由 :doc:`create_filter_form <m_create_filter_form>` 方法触发。

``item`` 参数是触发了这个事件的实体项。
