==================
on_edit_form_keyup
==================

on_edit_form_keyup(item, event)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

``on_edit_form_keyup`` 事件在实体项的 :doc:`edit form <at_edit_form>` 上发生 keyup 事件时被触发。

``item`` 参数是触发了这个事件的实体项。

``event`` 是一个 JQuery 事件对象。
