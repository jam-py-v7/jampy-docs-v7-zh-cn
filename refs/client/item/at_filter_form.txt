===========
filter_form
===========

.. js:attribute:: filter_form

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

Use ``filter_form`` attribute to get access to a Jquery object representing the 
filter form of the item. 
使用 ``filter_form`` 属性获取对一个表示为实体项的过滤器窗体的 JQuery 对象的访问权限。

它由 :doc:`create_filter_form <m_create_filter_form>` 方法创建。

:doc:`close_filter_form <m_close_filter_form>` 方法将 ``filter_form`` 的值设置为 undefined 。

示例
=======

In the following example the button defined in the item filter html template is 
assigned a click event:

在以下示例中，实体项过滤器的 html 模板中定义的按钮被分配了一个点击事件：

.. code-block:: js

    item.filter_form.find("#cancel-btn").on('click', 
        function() {
            item.close_filter()
        }
    );
