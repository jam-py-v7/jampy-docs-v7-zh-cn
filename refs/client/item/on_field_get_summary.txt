====================
on_field_get_summary
====================

on_field_get_summary(field, value)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

编写 ``on_field_get_summary`` 事件处理程序，
来指定将被插入到字段的汇总单元格中的 ``summary`` 。

``field`` 参数是一个字段，它的 :doc:`on_field_get_summary </refs/client/item/on_field_get_summary>` 已经被处理。要获取拥有此字段的实体项，请使用字段的 :doc:`owner </refs/client/field/at_owner>` 属性。
 
Example
=======

.. code-block:: js

        function on_field_get_summary(field, value) {
            let item = field.owner;
            if (field.field_name === 'customer') {
                return item.rec_count;
            }
            // to use with Virtual Table           
            if (field.field_name === 'total') {
                let sum = 0;
                item.each(function(row) {
                    sum += parseFloat(row.total.value) || 0;
                });
                return '$' + sum.toFixed(2);
            }
        }
