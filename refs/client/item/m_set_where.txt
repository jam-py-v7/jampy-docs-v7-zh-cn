=========
set_where
=========

.. js:function:: set_where(where)

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

当没指定 :doc:`open <m_open>` 方法的可选参数 ``_where`` 时，
使用 ``set__where`` 在内部定义并存储 :doc:`open <m_open>` 方法使用的 ``_where`` 参数。

在执行 :doc:`open <m_open>` 方法之后，它将清除这些在内部存储的值。

``where`` 参数是一个由 “键-值” 对组成的对象。“键” 是字段的名称，紧跟冒号 “:”，之后是过滤器符号。
(参见 :doc:`过滤记录 </programming/data/filtering_records>` )。


示例
=======

以下代码片段的执行结果相同：

.. code-block:: js

    item.open({where: {id: 100}});

.. code-block:: js

    item.set_where({id: 100});
    item.open();
