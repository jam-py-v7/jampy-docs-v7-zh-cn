=================
on_field_get_text
=================

on_field_get_text(field)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

编写 ``on_field_get_text`` 事件处理程序，
来指定将被插入到字段的单元格中的 ``text`` 。

``field`` 参数是一个字段，
它的 :doc:`display_text </refs/client/field/at_display_text>` 已经被处理。
要获取拥有此字段的实体项，请使用字段的 :doc:`owner </refs/client/field/at_owner>` 属性。

该函数用于连接两个或多个字段进行显示。这些字段可以是其他表中的任何可以访问的字段。

Example
=======

.. code-block:: js

    function on_field_get_text(field) {
        if (field.field_name === 'customer' && field.value) {
            return field.owner.firstname.lookup_text + ' ' + field.lookup_text;
        }
    }
