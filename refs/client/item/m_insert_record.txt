=============
insert_record
=============

.. js:function:: insert_record(container) 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

打开数据集开头的一个新的空记录，并创建一个 
:doc:`edit_form <at_edit_form>`
用于可视化编辑记录。

如果指定了 ``container`` 参数（DOM 元素的 Jquery 对象），则编辑表单的 HTML 模板将插入到该容器中。

如果未指定 ``container`` 参数，
但在 :doc:`Edit Form Dialog </admin/items/edit_form_dialog>` 中设置了 
**Modeless form** 属性，或者通过编程设置了 
:doc:`edit_options <at_edit_options>` 的 modeless 属性，并且任务具有 
:doc:`forms_in_tabs </refs/client/task/at_forms_in_tabs>`
属性设置，且应用程序没有模态表单，则将在任务的 
:doc:`forms_container </refs/client/task/at_forms_container>` 
对象的新选项卡中创建无模式编辑表单。

在所有其他情况下，将创建模态表单。

如果允许在无模式下插入记录，应用程序将调用 :doc:`copy <m_copy>` 
方法来创建项目的副本。此副本将用于插入记录。 

``insert_record`` 方法 

* 调用 :doc:`can_create <m_can_create>` 
  方法检查用户是否有权插入记录，如果没有，则返回
  
* 检查项目是否处于编辑或插入 :doc:`state <at_item_state>` ，
  如果不是，则调用 :doc:`insert <m_insert>` 方法插入记录
  
* 调用 :doc:`create_edit_form <m_create_edit_form>` 
  方法创建用于记录可视化编辑的表单。
