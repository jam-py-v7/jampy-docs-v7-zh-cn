====================
process_table_row
====================

process_table_row(row, item)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

这是一个分配给 row_callback 的函数。
第一个参数是表格行的 JQuery 对象，而 item 参数是表格实体项的副本。

Example
=======

.. code-block:: js

        function process_table_row(row, item) {
            row.css('background-color', 'gray');
        }

        function on_view_form_created(item) {
            item.table_options.striped = false;
            item.table_options.row_callback = process_table_row;
        }
