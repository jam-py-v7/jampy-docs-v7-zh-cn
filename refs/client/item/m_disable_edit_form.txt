=================
disable_edit_form
=================

.. js:function:: disable_edit_form()

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

当 :doc:`edit_form <at_edit_form>` 可见时，调用 ``disable_edit_form`` 方法可以阻止任何用户的操作。

调用 :doc:`enable_edit_form <m_enable_edit_form>` 方法重新启用编辑表单对窗体。

示例
=======

.. code-block:: js

  function on_edit_form_created(item) {
      var save_btn = item.add_edit_button('Save and continue');
      save_btn.click(function() {
          if (item.is_changing()) {
              item.disable_edit_form();
              item.post();
              item.apply(function(error){
                  if (error) {
                      item.alert_error(error);
                  }
                  item.edit();                
                  item.enable_edit_form();
              });
          }
      });
  }
