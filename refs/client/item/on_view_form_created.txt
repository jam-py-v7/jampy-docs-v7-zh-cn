====================
on_view_form_created
====================

on_view_form_created(item)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

``on_view_form_created`` 事件，在表单窗体被创建但还未显示之前，由 
:doc:`view <m_view>` 方法触发。

``item`` 参数是触发了这个事件的实体项。

在 :doc:`Demo project </intro/demo_project>` 中，有使用了 **on_view_form_created** 的代码。
