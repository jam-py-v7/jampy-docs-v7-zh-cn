===
eof
===

.. js:function:: eof() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``eof`` (end-of-file) 来确定游标是否指向一个实体项数据集的最后一条记录。 
如果 eof 返回 ``true``, 游标就明确地位于数据集中的最后一行上。

eof 返回 true ，当应用程序：

* 打开一个空数据集。.
* 调用了实体项的 :doc:`last <m_last>` 方法。
* 调用了实体项的  :doc:`next <m_next>` 方法，并且执行失败
  （因为游标已经在数据集的最后一行上）。

在其它情况下， eof 返回 false 。

.. note::
    如果 eof 和 :doc:`bof <m_bof>` 都返回 ``true``, 则实体项数据集是空的。
