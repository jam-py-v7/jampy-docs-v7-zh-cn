=========
view_form
=========

.. js:attribute:: view_form

**使用范围**: client  

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

使用 ``view_form`` 属性访问表示实体项视图表单的 Jquery 对象。

它由 :doc:`view <m_view>` 方法创建。

:doc:`close_view_form <m_close_view_form>` 方法会将 ``view_form`` 的值设置为 undefined 。

示例
=======

在下面的示例中，在实体项的 html 模板中定义的按钮上分配了一个 click 事件：

.. code-block:: js

    item.view_form.find("#new-btn").on('click', 
        function() {
            item.insert_record();
        }
    );
