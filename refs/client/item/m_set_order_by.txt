============
set_order_by
============

.. js:function:: set_order_by(field_list)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

当没指定 :doc:`open <m_open>` 方法的可选参数 ``order_by`` 时，
使用 ``set_order_by`` 在内部定义并存储 :doc:`open <m_open>` 方法使用的 ``order_by`` 参数。

在执行 :doc:`open <m_open>` 方法之后，它将清除这些在内部存储的值。

``field_list`` 参数一个由字段名组成的列表。如果在一个字段名称前添加了符号 “-” ，那么将存储按这个字段降序排序后的记录。


Example
=======

以下代码片段的执行结果相同：

.. code-block:: js

    item.open({order_by: ['-invoicedate']});

.. code-block:: js

    item.set_order_by(['-invoicedate']);
    item.open();
