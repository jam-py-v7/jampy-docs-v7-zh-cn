==========
is_edited
==========

.. js:function:: is_edited() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

检查一个实体项是否处于 “编辑” 状体。如果是，则返回 ``true`` 。

应用程序通过调用 :doc:`edit <m_edit>` 方法可以将一个实体项置于 “编辑” 状态，
