==========
set_fields
==========

.. js:function:: set_fields(field_list)

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

当没指定 :doc:`open <m_open>` 方法的可选参数 ``fields`` 时，
使用 ``set_fields`` 在内部定义并存储 :doc:`open <m_open>` 方法使用的 ``fields`` 参数。

在执行 :doc:`open <m_open>` 方法之后，它将清除这在些内部存储的值。

``field_list`` 参数一个由字段名组成的列表。

示例
=======

以下代码片段的执行结果相同：

.. code-block:: js

    item.open({fields: ['id', 'invoicedate']});

.. code-block:: js

    item.set_fields(['id', 'invoicedate']);
    item.open();
