==================
on_view_form_shown
==================

on_view_form_shown(item)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

**on_view_form_shown** 事件在表单窗体已经显示后由 :doc:`view <m_view>` 方法触发。

``item`` 参数是触发了这个事件的实体项。
