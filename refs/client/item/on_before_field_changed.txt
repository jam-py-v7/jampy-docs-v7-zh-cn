=======================
on_before_field_changed
=======================

on_before_field_changed(field)

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

编写 ``on_before_field_changed`` 事件处理程序，在字段数据更改之前执行任何特殊处理。

``field`` 参数是其数据设计到变更的字段。

获取拥有字段的实体项，使用字段的 :doc:`owner </refs/client/field/at_owner>` 属性。

在触发此事件处理程序之前，应用程序将要设置的新值分配给字段的 “new_value” 属性。
您可以更改此属性的值。此值将用于更改字段的数据。 


示例
=======

.. code-block:: js

    function on_before_field_changed(field) {
        if (field.field_name === 'quantity' && field.new_value < 0) {
            field.new_value = 0;
        }
    }
