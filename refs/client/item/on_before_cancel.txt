================
on_before_cancel
================

on_before_cancel(item)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

应用程序取消对实体项数据集的修改之前发生此事件。

``item`` 参数是触发了这个事件的实体项。

编写一个 ``on_before_cancel`` 事件处理程序，应用程序在取消对实体项数据集的修改之前，立即执行指定的操作。
