========
can_edit
========

.. js:function:: can_edit()

**domain**: client 

**language**: javascript

**class** :doc:`Item </refs/client/item_api>`

Description
===========

使用 ``can_edit`` 方法确定一个用户是否有权限编辑一个实体项数据集中的记录。

当设置了项目 :doc:`安全模式参数 </admin/project/parameters>` 以及 :doc:`permissions <at_permissions>` 属性和 :doc:`can_modify <at_can_modify>` 属性的值时，此方法考虑了在应用程序生成器的 :doc:`角色节点 </admin/roles>` 中设置的用户权限。

Example
=======

.. code-block:: js

    if (item.can_edit()) {
        item.view_form.find("#edit-btn").on('click', 
            function() {
                item.edit_record();
            }
        );
    }
    else {
        item.view_form.find("#edit-btn").prop("disabled", true);
    }
