=============
on_after_edit
=============

on_after_edit(item)

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

应用程序编辑一条记录之后发生此事件。

``item`` 参数是触发了这个事件的实体项。

编写一个 ``on_after_edit`` 事件处理程序，应用程序在编辑一条记录之后，立即执行指定的操作。

``on_after_edit`` 由 by :doc:`edit <m_edit>` 调用。
