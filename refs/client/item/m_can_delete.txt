==========
can_delete
==========

.. js:function:: can_delete()

**domain**: client 

**language**: javascript

**class** :doc:`Item </refs/client/item_api>`

Description
===========

使用 ``can_delete`` 方法确定一个用户是否有权限删除一个属于实体项数据集的记录。

当设置了项目 :doc:`安全模式参数 </admin/project/parameters>` 以及 :doc:`permissions <at_permissions>` 属性和 :doc:`can_modify <at_can_modify>` 属性的值时，此方法考虑了在应用程序生成器的 :doc:`角色节点 </admin/roles>` 中设置的用户权限。

Example
=======

.. code-block:: js

    if (item.can_delete()) {
        item.view_form.find("#delete-btn").on('click', 
            function() {
                item.delete_record();
            }
        );
    }
    else {
        item.view_form.find("#delete-btn").prop("disabled", true);
    }
