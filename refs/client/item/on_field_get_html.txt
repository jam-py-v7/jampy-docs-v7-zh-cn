=================
on_field_get_html
=================

on_field_get_html(field)

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

编写 ``on_field_get_html`` 事件处理程序来指定在表格中将插入到该字段的单元格中的 ``html`` ，

如果事件处理程序没有返回任何值，应用程序检查是否定义了 :doc:`on_field_get_text <on_field_get_text>` 事件处理程序；如果返回了一个值，将使用 :doc:`display_text </refs/client/field/at_display_text>` 属性的值在单元格中来显示该字段的值。

``field`` 参数是一个字段，
它的 :doc:`display_text </refs/client/field/at_display_text>` 已经被处理。
要获取拥有此字段的实体项，请使用字段的 :doc:`owner </refs/client/field/at_owner>` 属性。

示例
=======

.. code-block:: js

  function on_field_get_html(field) {
      if (field.field_name === 'total') {
          if (field.value > 10) {
              return '<strong>' + field.display_text + '</strong>';
          }
      }
  }
