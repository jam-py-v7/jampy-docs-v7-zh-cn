=============
delete_record
=============

.. js:function:: delete_record() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

* 调用 :doc:`can_delete <m_can_delete>` 方法检查一个用户是否有权限删除操作的记录，
  如果没有权限，则直接返回。
  
* 如果用户有权限，则要求用户是否确认操作。

* 调用 :doc:`delete <m_delete>` 方法删除操作的记录。
  
* 调用 :doc:`apply <m_apply>` 方法将变更写入应用程序数据库。
