====================
on_edit_form_created
====================

on_edit_form_created(item)

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

``on_edit_form_created`` 事件，在表单窗体被创建但还未显示之前，由实体项的 
:doc:`create_edit_form <m_create_edit_form>` 方法触发。

``item`` 参数是触发了这个事件的实体项。

:doc:`演示项目 </intro/demo_project>` 使用下面的代码将 “发票(Invoices)” 数据表的 read_only 字段设置为 ``paid`` 字段的值，并删除页脚：

.. code-block:: js

    function on_edit_form_created(item) {
        item.read_only = item.paid.value;
        item.edit_form.find('.form-footer').remove();
    }
