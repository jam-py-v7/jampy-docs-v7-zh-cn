============
view_options
============

.. js:attribute:: view_options

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

``view_options`` 属性是一个选项的集合，它们决定视图表单在浏览器页面上将如何显示。

在应用程序构建器的 :doc:`视图表单对话框 </admin/items/view_form_dialog>` 里面对这些选项进行设置。

你可以在实体项的 :doc:`on_view_form_created <on_view_form_created>` 事件处理程序历更改 ``view_options`` ，请见示例。

``view_options`` 是一个有下列属性的对象：

=================== ============================================================
Option              Description
=================== ============================================================
width               模态表单窗体的宽度，默认值是 600 px 。

title               表单窗体的标题，其默认值是 :doc:`item_caption </refs/client/abstr_item/at_item_caption>` 属性的值。

form_border         如果为 true，表单窗体周围会显示边框。

form_header         如果为 true，将创建包含表单窗体的标题和各种按钮的标题栏。

history_button      如果为 true 并且 :doc:`启用保存变更历史 
                    </admin/saving_history>` ，
                    那么将在表单标题栏内显示 “保存变更历史按钮” 。

refresh_button      如果为 true，那么将在表单标题栏内创建 “刷新按钮” ，
                    这允许用户向服务端发送请求来刷新页面。

enable_search       if true, the search input will be created in the form header
                    如果为 true，那么将在表单标题栏内创建 “搜索输入框” 。

search_field        默认的搜索字段的名称

enable_filters      如果为 true 并且有可用的可见的过滤器，
                    那么将在表单标题栏内创建 “搜过滤器按钮” 。

close_button        如果为 true，那么将在表单右上角创建 “关闭按钮” 。
  
close_on_escape     如果为 true，按下 Escape 键会执行
                    :doc:`close_view_form <m_close_view_form>` 来关闭表单窗体。

view_details        明细项名称的列表，如果视图表单模板包含样式类为 
                    'view-detail' 的 div （默认的视图表单模板已包含），
                    它们将显示在视图表单中，

detail_height       在视图表单中显示的明细表的高度，
                    如果没有指定，那么明细表的高度是 200px。

modeless            如果为 true，表单窗体将以非模态显示。

template_class      如果指定，将在 “任务” 的 
                    :doc:`templates </refs/client/task/at_templates>` 
                    属性中搜索具有此类的 div ，并在创建表单时用作表单 html 模板。
                    必须在创建表单之前设置此属性
=================== ============================================================

示例
=======

.. code-block:: js

    function on_view_form_created(item) {
        item.view_options.width = 800;
        item.view_options.close_button = false;
        item.view_options.close_on_escape = false;    
    }
