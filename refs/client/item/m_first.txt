=====
first
=====

.. js:function:: first() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``first`` 将光标定位在实体项数据集中的第一条记录上，并使其成为活动记录。
``first`` 会将任何更改提交到活动的记录中。
