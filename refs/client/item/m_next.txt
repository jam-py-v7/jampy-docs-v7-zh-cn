====
next
====

.. js:function:: next() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``next`` 方法将游标移到实体项数据集的下一条记录上，
并使之成为 “活动(active)” 记录。 ``next`` 会提交当前 “活动” 记录的变更。
