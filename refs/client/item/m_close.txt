=====
close
=====

.. js:function:: close() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``close`` 方法关闭实体项的数据集。
在数据集被关闭后， :doc:`active <at_active>` 属性是 ``false``。
