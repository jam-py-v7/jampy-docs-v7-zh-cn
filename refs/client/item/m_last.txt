====
last
====

.. js:function:: last() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``last`` 方法将游标移到实体项数据集的最后一条记录上，
并使之成为 “活动(active)” 记录。
