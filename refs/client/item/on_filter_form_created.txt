======================
on_filter_form_created
======================

on_filter_form_created(item)

The item parameter is the item that triggered the event.

**domain**: client 

**language**: javascript

Description
===========

``on_filter_form_created`` 事件，在表单窗体被创建但还未显示之前，由实体项的 
:doc:`create_filter_form <m_create_filter_form>` 方法触发。

``item`` 参数是触发了这个事件的实体项。
