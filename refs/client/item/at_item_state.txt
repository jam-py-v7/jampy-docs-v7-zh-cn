==========
item_state
==========

.. js:attribute:: item_state

**domain**: client 

**language**: javascript

**class** :doc:`Item </refs/client/item_api>`

Description
===========

检查  ``item_state`` 以确定实体项的当前操作模式。
Item_state 决定了可以对一个实体项中的数据集进行哪些操作，例如编辑已存在额记录，或者插入新记录。 ``item_state`` 在应用程序处理数据时不断变化。
Opening a item changes state from inactive to browse.
打开一个实体项会将数据集的状态由不活动状态变为浏览状态。应用程序可以调用 :doc:`edit <m_edit>` 将实体项置于编辑状态，或者调用 :doc:`insert <m_insert>` 或 :doc:`append <m_append>` 将实体项置于插入状态。

提交或取消编辑、插入或删除，将使 ``item_state`` 从实体项的当前状态变为浏览状态。
关闭一个数据集，将使其处于不活动状态。

要检查 item_state 的值，请使用下面的方法：

* :doc:`is_new <m_is_new>` - 指明实体项是否处于插入状态
* :doc:`is_edited <m_is_editing>` - 指明实体项是否处于编辑状态
* :doc:`is_changing <m_is_changing>` - 指明实体项是否处于编辑或插入状态

item_state 的值，可以是：

* 0 - 不活动状态
* 1 - 浏览状态
* 2 - 插入状态
* 3 - 编辑状态
* 4 - 删除状态

item :doc:`task </refs/client/abstr_item/at_task>` attribute have consts object 
that defines following attributes:
实体项的 :doc:`task </refs/client/abstr_item/at_task>` 属性有一个常量对象，它有下列属性：

* "STATE_INACTIVE": 0,
* "STATE_BROWSE": 1,
* "STATE_INSERT": 2,
* "STATE_EDIT": 3,
* "STATE_DELETE": 4

因此，可以使用下列方法检查实体项是否处于插入状态：

::

    item.item_state === 2

or:: 

    item.item_state === item.task.consts.STATE_INSERT
 
or:: 

    item.is_new()
