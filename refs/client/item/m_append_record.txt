=============
append_record
=============

.. js:function:: append_record(container) 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

在数据集末尾，打开一个新的空记录，并创建一个 :doc:`edit_form <at_edit_form>` 用于记录的可视化编辑。

如果指定了 ``container`` 参数（DOM 元素的 JQuery 对象），那么编辑表单的 html 模板会被添加到容器（container）里面。

如果未指定 ``container`` 参数，但在 :doc:`编辑表单对话框 
</admin/items/edit_form_dialog>` 中设置了 **无模式表单(Modeless form)** 属性，
或者以编程方式设置了 :doc:`edit_options <at_edit_options>` 的无模式属性，并且
设置了任务的  :doc:`forms_in_tabs </refs/client/task/at_forms_in_tabs>` 属性，
而应用程序没有模式表单，则将在任务的 
:doc:`forms_container </refs/client/task/at_forms_container>` 
对象的新选项卡中创建无模式编辑表单。

在其它情况下，将创建模态表单窗体。

如果在非模态模式下允许添加记录，应用程序会调用 :doc:`copy <m_copy>` 方法创建实体项的一个副本。这个副本用来添加新记录。

``append_record`` 方法：

* 调用 :doc:`can_create <m_can_create>` 方法检查一个用户是否有权限添加记录，
  如果没有权限，则

* 检查实体项是否处于编辑或插入 :doc:`状态 <at_item_state>` ，
  如果不是，则调用 :doc:`append <m_append>` 方法添加一个新记录，

* 调用 :doc:`create_edit_form <m_create_edit_form>` 方法
  创建一个用于记录的可视化编辑的表单窗体。
