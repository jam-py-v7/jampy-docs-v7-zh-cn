============
record_count
============

.. js:function:: record_count() 

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

Call ``record_count`` to get the total number of records owned by the item's 
dataset.
调用 ``record_count`` 方法获取实体项的数据集拥有的记录的总数。

示例
=======

.. code-block:: js

    item.open()
    if (item.record_count()) {
        // some code
    }
