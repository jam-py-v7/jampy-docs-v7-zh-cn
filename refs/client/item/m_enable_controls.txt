===============
enable_controls
===============

.. js:function:: enable_controls() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``enable_controls`` 方法以允许在数据感知控件中显示数据，并在之前调用 :doc:`disable_controls <m_disable_controls>` 后再重新绘制它们。
