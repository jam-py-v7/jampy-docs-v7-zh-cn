=========
rec_count
=========

.. js:attribute:: rec_count

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

读取 ``rec_count`` 属性以获取实体项数据集所拥有的记录的数量。

如果在模块中声明了一个 :doc:`on_filter_record <on_filter_record>` 事件处理程序，并且设置了 :doc:`Filtered <at_filtered>` 属性， ``rec_count`` 属性计算经过过滤后的记录的数量，否则使用 :doc:`record_count <m_record_count>` 方法计算记录的数量。

另请参见
========

:doc:`record_count <m_record_count>`

示例
=======

.. code-block:: js

  function edit_invoice(invoice_id) {
      var invoices = task.invoices.copy();
      invoices.open({ where: {id: invoice_id} }, function() {
          if (invoices.rec_count) {
              invoices.edit_record();
          }
          else {
              invoices.alert_error('Invoices: record not found.');
          }
      });
  }
