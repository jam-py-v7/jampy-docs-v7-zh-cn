================
create_view_form
================

.. js:function:: create_view_form(container)

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

使用 ``create_view_form`` 方法创建实体项的视图表单。

该方法在 “任务” 的 :doc:`templates </refs/client/task/at_templates>` 
属性里搜索实体项的 html 模板
（请见 :doc:`表单窗体 </programming/interface/forms>` ），
然后创建模板的一个副本并将其分配给实体项的 :doc:`view_form <at_view_form>` 属性。

如果指定了 ``container`` 参数，则该方法将其清空并将 html 模板附加到该参数上。
否则，它将创建一个模态表单并将 html 附加到该表单上。

触发 “任务” 的 
:doc:`on_view_form_created </refs/client/task/on_view_form_created>` 
事件。

如果为实体项所属的组定义了 
:doc:`on_view_form_created </refs/client/group/on_view_form_created>` 
事件, 那么触发定义的事件。

如果为实体定义了 
:doc:`on_view_form_created <on_view_form_created>` 
事件, 那么触发定义的事件。

将 JQuery 的 keyup 和 keydown 事件分配给 edit_form 后，当窗体的 JQuer 事件发生时，会触发 ``on_view_form_keyup`` 和 ``on_view_form_keydown`` 事件。会以相同的方法触发已定义的事件：首先是 “任务” 的事件处理程序，然后是 “组” 的事件处理程序，最后是实体项自己的事件处理程序。之后，调用事件的 JQuery stopPropagation 方法。

如果表单是模态形式，则显示它。在显示表单之前，该方法会先启用在 :doc:`view_options <at_view_options>` 属性里指定的选项。

触发 “任务” 的 
:doc:`on_view_form_shown </refs/client/task/on_view_form_shown>` 
事件。

如果为实体项所属的组定义了 
:doc:`on_view_form_shown </refs/client/group/on_view_form_shown>` 
事件, 那么触发定义的事件。

如果为实体定义了 
:doc:`on_view_form_shown <on_view_form_shown>`  
事件, 那么触发定义的事件。
