===========
each_filter
===========

.. js:function:: each_filter(function(filter))

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Item 类 </refs/client/item_api>`

描述说明
===========

使用 ``each_filter`` 方法来迭代访问一个实体项所拥有的 :doc:`filters <at_filters>` 。

``each_filter`` 方法指定了一个函数，这个函数会为实体项的每个过滤器执行。
（当前过滤器作为参数传递给该方法）

通过使回调函数返回 ``false`` ，你能在一个特定的迭代中终止 each_filter 循环。

示例
=======

.. code-block:: js

    function customer_filters(customers) {
        customers.each_filter(function(f) {
            console.log(f.filter_caption, f.value);
        });
    }
