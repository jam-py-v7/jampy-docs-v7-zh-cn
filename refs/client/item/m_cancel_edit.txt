===========
cancel_edit
===========

.. js:function:: cancel_edit() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

取消记录的可视化编辑

``cancel_edit`` 方法

* 调用 :doc:`close_edit_form <m_close_edit_form>` 方法以销毁 edit_form

* 调用 :doc:`cancel <m_cancel>` 方法以撤销对记录所做的修改。
