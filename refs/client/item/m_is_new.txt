======
is_new
======

.. js:function:: is_new() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

检查一个实体项是否处于 “插入” 状体。 如果是，则返回 ``true`` 。

应用程序通过调用 :doc:`append <m_append>` 或者 :doc:`insert <m_insert>` 方法
可以将一个实体项置于 “插入” 状态。
