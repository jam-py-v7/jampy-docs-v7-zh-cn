=====
prior
=====

.. js:function:: prior() 

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

调用 ``prior`` 将游标定位在实体项数据集中的前一条记录上，并使其成为活动记录。最后，提交对活动记录的任何更改。
