======
delete
======

.. js:function:: delete()

**domain**: client 

**language**: javascript

**class** :doc:`Item class </refs/client/item_api>`

Description
===========

删除活动的记录，并将游标移到下一条记录上。

``delete`` 方法

* 检查实体项数据集是否处于:doc:`active <at_active>` 状态。
  如果不是，则引发异常。

* 检查实体项数据集是否不为空。如果为空，则引发异常。

* 如果实体项是一个 :doc:`明细项 </programming/data/details>` ，
  那么检查其主实体项是否处于 “编辑” 或 “插入”  
  :doc:`状态 <at_item_state>` ，如果不是，则引发异常。
  
* 如果实体项不是一个 :doc:`明细项 </programming/data/details>` ，
  那么检查其是否处于 “浏览” :doc:`状态 <at_item_state>` ，
  如果不是，则引发异常。
  
* 触发为实体项定义的 :doc:`on_before_delete <on_before_delete>` 事件处理程序。
  
* 将实体项置于 “删除” :doc:`状态 <at_item_state>` 。

* 删除活动的记录，并将游标移到下一条记录。

* 将实体项置于 “浏览”  :doc:`状态 <at_item_state>`

* 触发为实体项定义的 :doc:`on_after_delete <on_after_delete>`  事件处理程序。

* 更新 :doc:`数据感知控件 </programming/interface/data_controls>`
