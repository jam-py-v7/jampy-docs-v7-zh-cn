==================
on_edit_form_keyup
==================

on_edit_form_keyup(item, event)

**domain**: client 

**language**: javascript

**class** :doc:`Group class </refs/client/item_group_api>`

Description
===========

当按键的 keyup 事件发生在实体项的 :doc:`edit_form </refs/client/item/at_edit_form>` 表单上时，会触发 ``on_edit_form_keyup`` 事件。

``item`` 参数是触发事件的实体项。

``event`` 是 JQuery 事件对象。
