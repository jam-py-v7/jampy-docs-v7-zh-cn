=====
owner
=====

.. js:attribute:: owner

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Field 类 </refs/client/field_api>`


描述说明
===========

获取字段对象所属的实体项。

检查字段的 owner 属性的值，以确定将该字段对象作为其自身来显示的实体项。

示例
=======

.. code-block:: js

    function calculate(item) {

    }

    function on_field_changed(field, lookup_item) {
        if (field.field_name === 'taxrate') {
            calculate(field.owner);
        }
    }
