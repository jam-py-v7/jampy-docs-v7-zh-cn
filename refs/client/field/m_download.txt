========
download
========

.. js:function:: download() 

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Field 类 </refs/client/field_api>`

描述说明
===========

在类型为 FILE 的字段上调用 ``download`` 函数来下载字段存储的文件。

示例
=======

.. code-block:: js

  function on_view_form_created(item) {
    item.add_view_button('Download').click(function() {
       item.attachment.download(); 
    });
  }
