=====
value
=====

.. js:attribute:: value

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Field 类 </refs/client/field_api>`


描述说明
===========

使用 **value** 属性来获取或设置字段的值。

获取 value
-------------

当字段的类型是 “integer”、 “float” 或 “currency” 时，数据 **null** 将被转换为 **0** 。
如果字段类型是 “text” ，那么会转换为 *空字符串* 。

对于  :doc:`查找字段 </programming/data/lookup_fields>` ， value 属性是一个整数，
它是查找实体项中相应记录的 id 字段的值。要获取字段的查找的值，请使用 :doc:`lookup_value <at_lookup_value>` 属性。

设置 value
-------------

当指定了一个新值，字段会检查当前值是否不等于新指定的值。如果不等于，则

* 将 **new_value** 属性设置为新指定的值。
* 如果为字段定义了 :doc:`on_before_field_changed </refs/client/item/on_before_field_changed>` 事件处理程序，则会被触发。
* 将字段数据改为 **new_value** 属性的值，并将  **new_value**  设置为 **null** 。
* 将实体项标记为已被修改。因此，:doc:`is_modified </refs/client/item/m_is_modified>` 方法将返回 **true** 。
* 如果为字段定义了 :doc:`on_field_changed </refs/client/item/on_field_changed>` 事件处理程序，则会被触发。
* 更新数据感知控件
  
示例
=======

.. code-block:: js

    function calc_total(item) {
        item.amount.value = item.round(item.quantity.value * item.unitprice.value, 2);
        item.tax.value = item.round(item.amount.value * item.owner.taxrate.value / 100, 2);
        item.total.value = item.amount.value + item.tax.value;
    }
