====
text
====

.. js:attribute:: text

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Field 类 </refs/client/field_api>`


描述说明
===========

使用 **text** 属性来设置或获取字段的文本值。

获取 text 属性的值
---------------------------

获取 :doc:`value <at_value>` 属性的值，并将其转换为文本。

设置 text 属性的值
---------------------------

按字段的类型对文本进行转换，并将字段的 :doc:`value <at_value>` 属性指定为转换后的值。
