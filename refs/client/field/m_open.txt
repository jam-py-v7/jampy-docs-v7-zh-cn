====
open
====

.. js:function:: open() 

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Field 类 </refs/client/field_api>`

描述说明
===========

在类型为 FILE 的字段上调用 ``open`` 函数，它会通过 ``window.open`` 方法来打开指向字段存储的文件的地址。

示例
=======

.. code-block:: js

  function on_view_form_created(item) {
    item.add_view_button('Open').click(function() {
       item.attachment.open(); 
    });
  }
