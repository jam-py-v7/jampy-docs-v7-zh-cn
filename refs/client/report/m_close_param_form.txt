================
close_param_form
================

.. js:function:: close_param_form()

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Report 类 </refs/client/report_api>`

描述说明
===========

使用 ``close_param_form`` 方法来关闭报表的参数表单窗体。

``close_param_form`` 方法会触发以为报表定义的 :doc:`on_param_form_close_query <on_param_form_close_query>` 事件处理程序。
如果定义了事件处理程序，并且

* 返回 true - 销毁表单窗体，将报表的 :doc:`param_form <at_param_form>` 
  属性设置为 undefined ，该方法退出。

* 返回 false - 操作中止，该方法退出。

如果它不返回值（undefined），该方法会触发以为所属报表所属组定义的 :doc:`on_param_form_close_query </refs/client/reports/on_param_form_close_query>` 事件。如果此事件处理程序已定义，并且

* 返回 true - 表单被表单窗体，报表的 :doc:`param_form <at_param_form>` 属性被设置为 undefined，该方法退出
* 返回 false - 操作中止，该方法退出

如果它不返回值（undefined），该方法会触发任务的 :doc:`on_param_form_close_query </refs/client/task/on_param_form_close_query>`。如果此事件处理程序已定义，并且

* 返回 true - 表单被销毁，报表的 :doc:`param_form <at_param_form>` 属性被设置为 undefined，方法退出
* 返回 false - 操作中止，方法退出

如果没有定义事件处理程序，或者这些事件处理程序都未返回 false，则表单被销毁，并且报表的 :doc:`param_form <at_param_form>` 属性被设置为 undefined 。
