=============
param_options
=============

.. js:attribute:: param_options

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`Report 类 </refs/client/report_api>`

描述说明
===========

使用 ``param_options`` 属性指定模态参数表单的参数。

``param_options`` 是一个对象，具有以下属性：

* ``width`` - 模态表单的宽度，默认值为 560 px 。
* ``title`` - 模态表单的标题，默认值为 :doc:`report_caption </refs/client/abstr_item/at_item_caption>` 属性的值。
* ``close_button`` - 如果为 true，则在表单右上角创建关闭按钮，默认值为 true，
* ``close_caption`` - 如果为 true 且 ``close_button`` 为 true，则在按钮旁显示 “Close - [Esc]” 。
* ``close_on_escape`` - 如果为 true，按下 Escape 键将触发 :doc:`close_param_form <m_close_param_form>` 方法。
* ``close_focusout`` - 如果为 true，当表单失去焦点时将调用 :doc:`close_param_form <m_close_param_form>` 方法。
* ``template_class`` - 如果指定，则将在任务的 :doc:`templates </refs/client/task/at_templates>` 属性中查找具有此类的 div，并在创建表单时将其用作表单 HTML 模板。

示例
=======

.. code-block:: js

    function on_param_form_created(report) {
        report.param_options.width = 800;
        report.param_options.close_button = false;
        report.param_options.close_on_escape = false;    
    }
