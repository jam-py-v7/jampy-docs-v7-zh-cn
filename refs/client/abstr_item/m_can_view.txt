========
can_view
========

.. js:function:: can_view()

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`AbstractItem </refs/client/abstractitem_api>`

描述说明
===========

在勾选了项目的 :doc:`安全模式参数 </admin/project/parameters>` 后，
使用 **can_view** 方法就能确定某个用户是否有权限访问 :doc:`实体项 </refs/client/item_api>` 的数据集，
或生成的 :doc:`报表 </refs/client/report_api>` 结果。
如果为勾选项目的  :doc:`安全模式参数 </admin/project/parameters>` ，该方法总是返回 true。

用户权限是项目树中 :doc:`角色节点 </admin/roles>` 的子集。

示例
=======

.. code-block:: js

    if (item.visible && item.can_view()) {
        $("#submenu")
            .append($('<li></li>')
            .append(
                $('<a href=""></a>')
                    .text(item.item_caption)
                    .data('item', item);
            )
        );
    }
