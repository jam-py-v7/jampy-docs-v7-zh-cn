=========
each_item
=========

.. js:function:: each_item(function(item))

**使用范围**: client 

**编程语言**: javascript

**类**: :doc:`AbstractItem </refs/client/abstractitem_api>`

描述说明
===========

使用 each_item 方法来迭代访问某个实体项的  :doc:`items <at_items>` 属性中的实体项。

each_item() 可以指定一个函数来对每个子项进行处理（子项作为参数传递给该函数）。

通过使回调函数返回 false，你能在某个特定的迭代内中断 each_item 方法的循环，

示例
=======

以下代码将在浏览器的命令行中输出项目的全部主表目录（catalogs）：

.. code-block:: js

    function on_page_loaded(task) {
        task.catalogs.each_item(function(item) {
            console.log(item.item_name);
        })
    }
