====
load
====

.. js:function:: load(callback)

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Task </refs/client/task_api>`

描述说明
===========

当浏览器加载 index.html 文件中的 jam.js 库时， jam.js 会创建一个空的 “任务” 对象。
``Load`` 方法从服务器加载项目的 :doc:`任务树 </programming/task_tree>` ，并对其进行初始化。之后，应用程序会触发 :doc:`on_page_loaded <on_page_loaded>` 事件。
(参考 :doc:`工作流程 </programming/workflow>`) 

示例
=======

以下代码来自项目的 index.html 文件。

.. code-block:: html

    <script src="/jam/js/jam.js"></script>
    <script src="/js/events.js"></script>

    <script>
    $(document).ready(function(){
        task.load();
      });
    </script>
