=========
safe_mode
=========

.. js:attribute:: safe_mode

**使用范围**: client 

**编程语言**: javascript

**父类**: :doc:`Task </refs/client/task_api>`

描述说明
===========

检查 ``safe_mode`` 属性可以判断是否设置了项目的 :doc:`安全模式 </admin/project/parameters>` 参数

示例
=======

.. code-block:: js

    function on_page_loaded(task) {

        $("#title").html(task.item_caption);
        if (task.safe_mode) {
            $("#user-info").text(task.user_info.role_name + ' ' + task.user_info.user_name);
            $('#log-out')
            .show()
            .click(function(e) {
                e.preventDefault();
                task.logout();
            });
        }

        task.tasks.view($("#content"));
    }
