=========
item_type
=========

.. py:attribute:: item_type

**使用范围**: server

**编程语言**: python

**类**: :doc:`AbstractItem 类 </refs/server/abstractitem_api>`

描述说明
===========

指定实体项的类型。

使用 ``item_type`` 属性类获取实体项的类型。

它可以是下列值之一：

* “task” 
* “items” 
* “details” 
* “reports” 
* “item” 
* “detail_item” 
* “report” 
* “detail”
