============
hide_columns
============

.. py:method:: hide_columns(self, col_list)

**使用范围**: client 

**编程语言**: python

**父类**: :doc:`Report 类 </refs/server/report_api>`

描述说明
===========

使用 **hide_columns** 方法来隐藏在报表的 :doc:`template <at_template>` 中定义的一些列。

**col_list** 参数指定了应该隐藏娜些列。
这是由定义报表列的位置的整数或字母组成的一个列表。

请在 :doc:`on_parsed <on_parsed>` 事件处理程序里使用该方法。

示例
=======

.. code-block:: py

    def on_parsed(report):
        report.hide_columns(['A', 'C'])
    #    report.hide_columns([1, 3])
