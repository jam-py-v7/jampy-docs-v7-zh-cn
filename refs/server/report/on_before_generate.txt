==================
on_before_generate
==================

.. py:function:: on_before_generate(report)

**使用范围**: client 

**编程语言**: python

**类**: :doc:`Report 类 </refs/server/report_api>`

描述说明
===========

在生成报表之前， :doc:`generate <m_generate>`  方法会触发 
**on_before_generate** 事件。

**report** 参数是触发该事件的报表。
