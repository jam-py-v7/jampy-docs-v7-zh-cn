===========
on_generate
===========

.. py:function:: on_generate(report)

**使用范围**: client 

**编程语言**: python

**父类**: :doc:`Report 类 </refs/server/report_api>`

描述说明
===========

**on_generate** 事件由 :doc:`generate <m_generate>` 方法触发。

编写 **on_generate** 事件处理程序来生成报表的内容。
使用 :doc:`print_band <m_print_band>` 方法来打印在报表的 
:doc:`模板 </programming/reports/templates>` 中定义的区域。

**report** 参数是触发该事件的报表。
