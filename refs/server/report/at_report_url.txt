==========
report_url
==========

.. py:attribute:: report_url

**使用范围**: client 

**编程语言**: python

**父类**: :doc:`Report 类 </refs/server/report_api>`

描述说明
===========

:doc:`generate <m_generate>` 方法向客户端发送存储在该属性里的值，这个值是已生成文件的 url 。

当指定了报表的 :doc:`template <at_template>` 属性时，
:doc:`generate <m_generate>` 方法会，在保存已生成的内容后，设置该属性的值。
否则，开发人员必须自己设置该属性的值。
