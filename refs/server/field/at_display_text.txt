============
display_text
============

.. py:attribute:: display_text

**使用范围**: server

**编程语言**: python

:doc:`Field 类 </refs/server/field_api>`

描述说明
===========

将字段的值显示为字符串。

``Display_text`` 属性是一个只读字符串，它是字段的值面向用户的显示形式。
如果指派了一个 :doc:`on_field_get_text </refs/client/item/on_field_get_text>` 
事件，那么 **display_text** 是这个事件处理程序的返回值。
否则，display_text 的值是 
:doc:`查找字段 </programming/data/lookup_fields>` 的
:doc:`lookup_text <at_lookup_text>` 属性和 为其它字段设置的
:doc:`语言区域设置 </admin/language_support>` 的
:doc:`text <at_text>` 属性。

当字段不处于编状态时， ``Display_text`` 是字段的值属性的字符串表示形式。
当字段处于编状态时，将使用 :doc:`text <at_text>` 属性表示字段。


示例
=======

.. code-block:: py

    def on_generate(report):
        cust = report.task.customers.copy()
        cust.open()
    
        report.print_band('title')
    
        for c in cust:
            firstname = c.firstname.display_text
            lastname = c.lastname.display_text
            company = c.company.display_text
            country = c.country.display_text
            address = c.address.display_text
            phone = c.phone.display_text
            email = c.email.display_text
            report.print_band('detail', locals())
