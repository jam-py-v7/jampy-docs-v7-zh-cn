==========
field_type
==========

.. py:attribute:: field_type

**使用范围**: server

**编程语言**: python

:doc:`Field 类 </refs/server/field_api>`

描述说明
===========

指定字段对象的数据类型。

使用 ``field_type`` 属性了解字段包含的数据类型。

它是下列值之一：

* "text", 
* "integer", 
* "float",
* "currency", 
* "date", 
* "datetime", 
* "boolean", 
* "blob"
