============
lookup_value
============

.. py:attribute:: lookup_value

**使用范围**: server

**编程语言**: python

:doc:`Field 类 </refs/server/field_api>`

描述说明
===========

使用 ``lookup_value`` 属性来获取的 :doc:`查找字段 </programming/data/lookup_fields>`  的查找值。

如果字段是 :doc:`查找字段 </programming/data/lookup_fields>` ，
则得到是它的查找值（lookup value），
否则，得到的是 :doc:`value <at_value>` 的属性值。
