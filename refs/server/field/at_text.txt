====
text
====

.. py:attribute:: text

**使用范围**: server

**编程语言**: python

:doc:`Field 类 </refs/server/field_api>`

描述说明
===========

使用 ``text`` 属性来获取或色湖之字段的文本值（text value）。

获取文本属性值
---------------------------

获取 :doc:`value <at_value>` 属性的值，并将其转换为文本。

获取文本属性值
---------------------------

将文本值转换为字段的类型，并将其 :doc:`value <at_value>` 属性设置为转换后的值。
