=========
raw_value
=========

.. py:attribute:: raw_value

**使用范围**: server

**编程语言**: python

:doc:`Field 类 </refs/server/field_api>`

描述说明
===========

表示一个字读对象中的数据。

使用 ``raw_value`` 只读属性直接从实体项数据集读取数据。

像 :doc:`value <at_value>` 和 :doc:`text <at_text>` 等其它属性
将对字段的数据进行转换。

因此，数值字段的 :doc:`value <at_value>` 属性，会将 ``null`` 值转换为 ``0`` 。
