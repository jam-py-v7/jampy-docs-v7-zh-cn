=============
field_by_name
=============

.. py:method:: field_by_name(self, field_name)

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

当只知道字段名称时，可调用 ``field_by_name`` 方法来分析字段的信息。

``field_name`` 参数是已存在的字段的名称。

``field_by_name`` 方法返回通过名称指定的字段的字段对象。
如果指定的字段不存在，那么 ``field_by_name`` 方法返回  ``None`` 。
