==========
item_state
==========

.. py:attribute:: item_state

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

检查 ``item_state`` 属性来确定实体项当前所处的操作模式。 Item_state 决定了可以多实体项数据集进行那些操作，例如编辑已有的记录或者插入新记录。``item_state`` 在应用程序处理数据时不断变化。

打开一个实体项将使其由 “(不活动)inactive” 状态变为 “浏览(browse)” 状态。
应用程序通过调用 :doc:`edit <m_edit>` 方法可将一个实体置于 “编辑(edit)” 状态，
调用 :doc:`insert <m_insert>` 或 :doc:`append <m_append>` 
方法将一个实体项置于 “插入(insert)” 状态。

提交或取消编辑、插入、删除操作，会使实体项的 ``item_state`` 从当前状体变为 “浏览(browse)” 状态。
关闭一个数据集，会将其状态置于 “(不活动)inactive” 状体。

要检查 item_state 的值，请使用下列方法：

* :doc:`is_new <m_is_new>` - 指明实体项是否处于插入状体
* :doc:`is_edited <m_is_editing>` - 指明实体项是否处于编辑状体
* :doc:`is_changing <m_is_changing>` - 指明实体项是否处于插入或编辑状体

item_state 的值可以是：

* 0 - 非活动状态(inactive state)
* 1 - 浏览状态(browse state)
* 2 - 插入状态(insert state)
* 3 - 编辑状态(edit state)
* 4 - 删除状态(delete state)

实体项的 :doc:`task </refs/server/abstr_item/at_task>` 属性的 consts 属性有下列常量对象：

* "STATE_INACTIVE": 0,
* "STATE_BROWSE": 1,
* "STATE_INSERT": 2,
* "STATE_EDIT": 3,
* "STATE_DELETE": 4

so if the item is in edit state can be checked the following way:
因此，可以通过以下方法检查实体项是否处于编辑状态：
::

    item.item_state == 2

或者:: 

    item.item_state == item.task.consts.STATE_INSERT
 
或者:: 

    item.is_new()
