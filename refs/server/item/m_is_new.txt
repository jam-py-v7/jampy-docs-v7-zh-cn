======
is_new
======

.. py:function:: is_new(self) 

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

该方法检查实体项是否处于 “插入” 状体，如果是，则返回 true 。
应用程序可调用 :doc:`append <m_append>` 或 :doc:`insert <m_insert>` 
方法将实体项置于 “插入辑” 状体。
