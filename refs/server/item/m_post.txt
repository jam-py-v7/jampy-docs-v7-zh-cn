====
post
====

.. py:method:: post(self)

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

将修改后的记录写入到实体项数据集中。在调用 :doc:`append <m_append>` 、 :doc:`insert <m_insert>` 或 :doc:`edit <m_edit>` 方法之后，
调用 ``post`` 方法保存对记录的变更。

``post`` 方法：

* 检查实体项是否处于 “编辑” 或 “插入” :doc:`状体 <at_item_state>` 。
  如果不是，则抛出异常。

* 触发为实体项定义的 ``on_before_post`` 事件处理程序。

* 检查对应的记录是否有效，如果无效，则抛出异常。

* 如果实体项有 :doc:`details </programming/data/details>` ，
  那么提交明细项中的当前记录。

* 将变更添加到实体项的变更日志中。

* 将实体项置于 “浏览” :doc:`state <at_item_state>` 。

* 触发为实体项定义的 ``on_after_post`` 事件处理程序。
