======
rec_no
======

.. py:attribute:: rec_no

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

检查 ``rec_no`` 属性来确定实体项数据集中当前记录的记录号。

可以将 ``rec_no`` 设置为一个指定的记录号，以将数据游标定位到那条记录上。
