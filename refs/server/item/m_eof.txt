===
eof
===

.. py:method:: eof(self) 

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

使用 ``eof`` (end-of-file) 方法来判断游标是否指向了实体项数据集中的最后一条记录。
如果 ``eof`` 返回 true，那么明确地说明光标就位于数据集中的最后一行。 

当应用程序执行以下操作时， ``eof`` 方法返回 true ：

* 打开一个空的数据集
* 调用实体项的 :doc:`last <m_last>`  方法
* 调用实体项的 :doc:`next <m_next>` 方法，且方法执行失败
  （因为光标已经位于数据集中的最后一行上）

在其它情况下， eof 返回 false 。

.. note::

    如果 ``eof`` 和 :doc:`bof <m_bof>` 都返回 true，那么说明实体项数据集是空的。
