====
edit
====

.. py:method:: edit(self)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

允许数据集中的数据编辑功能。

调用一个 ``edit`` 方法之后，应用程序就允许用户更改记录的字段中的数据，
然后使用 :doc:`post <m_post>` 方法将这些更改提交到实体项的数据集中，
然后使用 :doc:`apply <m_apply>` 方法将更改应用到数据库中。

``edit`` 方法：

* 检查实体项数据集是否处于 “活动” 状体。如果不是，则抛出异常。

* 检查实体项数据集是否不为空。如果为空，则抛出异常。

* 检查实体项数据集是否已经处于 “编辑” 状体。如果是，则返回。

* 如果实体是一个 :doc:`明细项 </programming/data/details>` ，
  检查其主控项是否处于 “编辑” 或 “插入” :doc:`状体 <at_item_state>` 。
  如果不是，则抛出异常。

* 如果实体不是一个 :doc:`明细项 </programming/data/details>` ，
  检查其主控项是否处于 “浏览” :doc:`状体 <at_item_state>` 。
  如果不是，则抛出异常。

* 将实体置于 “编辑” :doc:`状体 <at_item_state>` ，
  允许应用程序或用户修改记录中的字段。
