=============
virtual_table
=============

.. py:attribute:: virtual_table

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

使用只读的 ``virtual_table`` 属性，
来确定实体项在项目的数据库中是否有一个相应的数据表。

如果 ``virtual_table`` 的值是 ``True`` ，那么在项目的数据库中，就没有与之对应的数据表。
你可以使用这样的实体项来处理内存中的数据集，或者使用它的模块编写代码。
调用 :doc:`open <m_open>` 方法会创建一个空的数据集，
而调用 :doc:`apply <m_apply>` 方法不起任何作用。
