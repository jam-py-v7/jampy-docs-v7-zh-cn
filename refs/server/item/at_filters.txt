=======
filters
=======

.. py:attribute:: filters

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

该属性列举出一个实体项数据集的所有 
:doc:`过滤器 </refs/server/filter_api>` 对象。

示例
=======

.. code-block:: py

    def invoices_filters(invoices):
        for f in invoices.filters:
            print f.filter_name, f.value
