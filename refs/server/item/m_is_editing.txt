==========
is_edited
==========

.. py:function:: is_edited(self) 

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

该方法检查实体项是否处于 “编辑” 状体，如果是，则返回 true 。
应用程序可调用 :doc:`edit <m_edit>` 方法将实体项置于 “编辑” 状体。
