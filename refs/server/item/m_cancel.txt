======
cancel
======

.. py:method:: cancel(self) 

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

只要更改没有被提交到实体项的数据集中，就能调用 ``cancel`` 方法以撤销对当前记录中一个或多个字段的修改。

``Cancel`` 方法：

* 触发为实体项定义的 ``on_before_cancel`` 事件处理程序。

* 如果对编辑了记录，则撤销对当前记录及其明细项的更改；
  如果添加或插入了新记录，则移除新记录。

* 将实体项置于 “浏览” :doc:`状态 <at_item_state>`

* 触发为实体项定义的 ``on_after_cancel`` 事件处理程序。
