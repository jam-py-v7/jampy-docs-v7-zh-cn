=====
prior
=====

.. py:method:: prior(self)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

调用 ``prior`` 方法使游标定位到实体项数据集中的前一条记录上，并使其成为 “活动” 记录。
``prior`` 会提交对活动记录的任何更改。
