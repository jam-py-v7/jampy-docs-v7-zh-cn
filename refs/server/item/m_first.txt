=====
first
=====

.. py:method:: first(self)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

调用 ``first`` 方法将游标定位到实体项数据集中的第一条记录上，并使其成为活动记录。
``first`` 方法会提交对活动记录的任何更改。
