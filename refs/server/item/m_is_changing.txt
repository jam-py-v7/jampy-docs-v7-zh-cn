===========
is_changing
===========

.. py:function:: is_changing(self) 

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

检查实体项是否处于 “编辑” 或 “插入” 状态，如果是，则返回 true 。

应用程序调用 :doc:`edit <m_edit>` 方式会将实体项置于 “编辑” 状态，
调用 :doc:`append <m_append>` 或 :doc:`insert <m_insert>` 
方法会将实体项置于 “插入” 状态。
