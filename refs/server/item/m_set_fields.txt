==========
set_fields
==========

.. py:method:: set_fields(self, lst=None, *fields)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

使用 ``set_fields`` 方法定义并存储内部存储 ``fields`` 参数 ，
未指定 ``fields`` 参数的 :doc:`open <m_open>` 方法将使用这些内部参数。
:doc:`open <m_open>` 方法会清除内部存储的该参数值。

``fields`` 是字段名的任意参数列表

参数
==========

你可以像客户端的 :doc:`set_fields </refs/client/item/m_set_fields>` 
方法那样，以列表形式指定字段，或者以非关键字参数的形式指定字段。

示例
=======

下列代码片段的执行结果相同：

.. code-block:: py

    item.open(fields=['id', 'invoicedate'])

.. code-block:: py

    item.set_fields('id', 'invoicedate')
    item.open()

.. code-block:: py

    item.set_fields(['id', 'invoicedate'])
    item.open()
