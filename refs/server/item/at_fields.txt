======
fields
======

.. py:attribute:: fields

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========


该属性列举出一个实体项数据集的所有 
:doc:`字段 </refs/client/field_api>` 对象。

示例
=======

.. code-block:: py

    def customer_fields(customers):
        customers.open(limit=1)
        for f in customers.fields:
            print f.field_caption, f.display_text
