==============
filter_by_name
==============

.. py:method:: filter_by_name(self, filter_name)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Item 类 </refs/server/item_api>`

描述说明
===========

当只知道过滤器名称时，可调用 ``filter_by_name``方法来分析过滤器的信息。

``filter_by_name`` 参数是已存在的过滤器的名称。

``filter_by_name``` 方法返回通过名称指定的过滤器的过滤器对象。
如果指定的过滤器不存在，那么 ``filter_by_name`` 方法返回  ``None`` 。
