==========
redirect
==========

.. py:method:: redirect(self, location, code=302, Response=None) 

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Task 类 </refs/server/task_api>`

描述说明
===========

使用  Werkzeug ``redirect`` 对象将客户端重定向到目标位置。

示例
=======

.. code-block:: py

	task.redirect('/login.html')
