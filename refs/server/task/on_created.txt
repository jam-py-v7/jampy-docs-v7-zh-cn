==========
on_created
==========

on_created(task)

**使用范围**: server

**编程语言**: python

**类**: :doc:`Task 类 </refs/server/task_api>`

描述说明
===========

在服务端，使用 ``on_created`` 事件初始化应用程序。

当项目的 :doc:`task 树 </programming/task_tree>` 刚刚被创建后，会触发该事件。
请见 :doc:`工作流 </programming/workflow>` 

``task`` 参数是指向 :doc:`task 树 </programming/task_tree>` 的一个引用。

.. note::

    在这个事件处理程序里的代码的执行时间必须非常短，因为这对最终用户的体验有很大影响。

示例
=======

.. code-block:: py

    def on_created(task):
        # some code
