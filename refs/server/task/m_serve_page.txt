==========
serve_page
==========

.. py:method:: serve_page(self, file_name, dic=None) 

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Task 类 </refs/server/task_api>`

描述说明
===========

使用 ``serve_page`` 方法向客户端发送一个 html 页面。
当前， ``serve_page`` 方法使用 Werkzeug Response 对象。

示例
=======

.. code-block:: py

	task.serve_page('index.html')
