=================
create_connection
=================

.. py:method:: create_connection(self) 

**使用范围**: server

**编程语言**: python

**父类**: :doc:`Task 类 </refs/server/task_api>`

描述说明
===========

使用 ``create_connection`` 来创建一个到项目数据库的连接。

该方法返回一个新连接。

不再需要一个连接后，开发者必须关闭它。
